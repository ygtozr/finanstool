# Finans Tool v5

Finans kodu girerek günlük kapanış fiyatlarını grafik üzerinde gösteren statik web uygulaması.

## Kullanım

- ABD hisseleri: `AAPL`, `MSFT`
- BIST hisseleri: `.IS` eki ile, örn. `THYAO.IS`, `ASELS.IS`
- Süre seçenekleri: 1 hafta, 1 ay, 3 ay, 6 ay, 1 yıl, 5 yıl veya özel başlangıç tarihi

Bu sürüm GitHub Pages üzerinde çalışması için tarayıcıdan açık veri uç noktasına erişir. Fiyat verisi Yahoo Finance'ten alınır; CORS geçişi için AllOrigins kullanılır.
