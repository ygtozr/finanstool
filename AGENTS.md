# Özer Finans çalışma başlangıcı

- Önce DEVIR_NOTLARI.md, ardından README.md ve URUN_VE_TEKNIK_TASARIM.md dosyalarını okuyun.
- Başlangıç kaynağı GitHub main dalıdır; onizleme ve archive altındaki kopyalar güncel uygulama değildir.
- Kullanıcının mevcut değişikliklerini koruyun. Düzenleme öncesi git status ve güncel uzak dalı kontrol edin.
- Yeni işlev/tasarım değişikliğini ayrı dalda önizleyin. Kullanıcı açıkça onaylamadan üretime göndermeyin.
- Kalıcı adres https://finanstool.vercel.app olarak kalmalıdır. Onaylı sürümde önceki sürümü arşivleyin, teknik belgeyi güncelleyin ve Git etiketi oluşturun.
- Mobil ölçüleri, düğme biçimleri, mevcut tercihleri, portföy verilerini ve JSON yedek uyumluluğunu koruyun.
- Regresyon testlerini çalıştırın. Görsel değişiklikleri mobil ve masaüstünde kontrol edin. Testin kapsamını açıkça belirtin; çevrimdışı test gerçek veri servisini doğrulamaz.
- Anahtar, parola, token veya kişisel portföy yedeğini GitHub'a koymayın. .env.example yalnız değişken adlarını içerir.
- Kullanıcıya aşama sonlarında kısa ve doğrulanabilir ilerleme bilgisi verin.
